## Projects

**VisualMemory — Real-Time Object Detection & Semantic Memory System** | `Python` `YOLOv8` `CLIP` `FAISS` `SQLite`
- Built a real-time visual memory system combining **YOLOv8** detection with **BoT-SORT** multi-object tracking to maintain persistent object identity across video frames
- Integrated **CLIP ViT-B/32** to generate visual and text embeddings, enabling semantic search over previously observed objects using natural language queries (e.g., *"Where is my laptop?"*)
- Designed a hybrid memory store using **FAISS** for vector similarity search and **SQLite** for structured metadata, supporting efficient retrieval at scale

**ASL Sign Language Recognition** | `Python` `MediaPipe` `PyTorch` `OpenCV` `NumPy`
- Built a real-time American Sign Language recognition system classifying hand gestures across all 26 alphabets using live webcam feed
- Leveraged **MediaPipe Hands** for hand landmark detection, extracting 21 keypoints per frame — no raw pixel-based CNN training needed
- Designed and trained a fully connected deep neural network in **PyTorch**, achieving **94–96% classification accuracy** across all ASL alphabet classes
- Applied data augmentation, normalization, and dropout regularization to reduce overfitting on limited hand gesture datasets
- Integrated a real-time inference pipeline with OpenCV for live video capture, preprocessing, and on-screen prediction display with low latency

**Early Sepsis Prediction Using Time-Series Patient Data** | `Python` `Pandas` `NumPy` `scikit-learn` `PyTorch`
- Developed a machine learning pipeline for early sepsis prediction using time-series ICU patient data
- Preprocessed individual patient files, performed feature engineering on vital signs, demographic and time-based clinical variables, and handled missing data with robust imputation techniques
- Built and validated predictive models including **LSTM/GRU** and ensemble tree methods, employing class balancing strategies (SMOTE, undersampling) to address severe class imbalance
- Visualized feature distributions, explored temporal patterns, and ensured workflow reproducibility

**Credit Card Fraud Detection Using Autoencoder Architecture** | `Python` `PyTorch` `scikit-learn` `Pandas`
- Built an unsupervised deep learning pipeline using **autoencoder networks** to detect fraudulent transactions from highly imbalanced datasets
- Performed data preprocessing, feature scaling, and dimensionality reduction to improve anomaly detection performance
- Designed and trained deep autoencoder models from scratch, optimizing reconstruction loss to identify abnormal transaction patterns with high precision
